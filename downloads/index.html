SirenSettingLimit Adjuster

Break the 20 siren limit and the 255 ID limit in GTA V.

Get the modTry the tools

What it does

The SirenSetting Limit Adjuster raises several emergency lighting limits in GTA V, so more vehicle mods can run side by side without clashing.

  • Per-vehicle siren limit raised from 20 to 32, so siren1 through siren32 all work independently
  • The siren_glass limit is raised to 32
  • Siren setting IDs are no longer capped at 255, and now go up to 65,535
  • Writes a SirenSettings log that lists conflicting IDs
  • Works with vehicles that have custom siren settings, with no special setup per vehicle

The 128 total bone limit on a vehicle still applies, so very detailed models can reach that first.

Which files do I install?

You use RPH

If you use RAGE Plugin Hook (RPH), install both files from the download.

You do not use RPH

If you do not use RPH, you only need the ASI file.

You sometimes use RPH

If you switch between playing with and without RPH, install both files.

Folder locations and the latest steps are in the author's download and on the LCPDFR page. Follow those if they differ from this summary.

Help and questions

My lights look exactly the same. Is it broken?

Most likely not. The adjuster mainly removes limits and conflicts. If your vehicles already used different IDs, you will not see a visible change. It helps when two vehicle mods share the same ID and end up with the same light setup.

Why do IDs matter?

Vehicles that do not use ELS get their emergency lighting from an entry in carcols.ymt, which is referenced by an ID number in carvariations.ymt. If two mods use the same ID, they get the same light setup. The default ID cap is 255, so clashes were easy to hit. The adjuster raises it to 65,535.

How do I find which IDs conflict?

Open the SirenSettings log the adjuster creates and search for the word Conflict. Every clashing ID is listed there. You can also paste your IDs into the checker above.

Does it work on FiveM?

This is a single-player GTA V mod. The author has said he is not sure whether it works on FiveM, and that it should work with FiveM-ready vehicles in normal single-player. It is not a FiveM server resource.

I get "log creation failed" or "error hooking".

Some players reported these errors in the comments on LCPDFR, and no fix was confirmed in the thread. Check you installed the right files for your setup, and read the latest comments on the author's page. LCPDFR tags this mod for the legacy game version.
